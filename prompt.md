# Prompt para usar como input de alguma Inteligência Artificial

```prompt
Tenho o feedback das respostas dos clientes sobre diferentes tipos de investimentos. AGORA: preciso de uma análise abrangente e minuciosa de tal feedback. Essa análise profunda serve para:
- identificar reclamações frequentes;
- identificar elogios;
- dúvidas recorrentes;
- identificar oportunidades de melhoria em cada categoria.
Então, os times da área de atendimento, a equipe de produtos e os gestores de portfólio vão usar essa análise para apoiar decisões sobre ajustes na comunicação, melhorias nos serviços e desenvolvimento de novas soluções financeiras específicas para cada tipo de investimento.
REGRAS DO FORMATO: a análise DEVE, rigorosamente, ser entregue com o seguinte:
- um resumo executivo;
- uma lista dos temas mais recorrentes por categoria de investimento;
- uma tabela dos problemas;
- uma tabela das ações sugeridas.
EXIGÊNCIAS: a análise é boa se tiver as seguintes qualidadas: 
- CLAREZA;
- COERÊNCIA;
- CONSISTÊNCIA;
- GOAL-DRIVENESS;
- ACTION-DRIVENNESS;
- ESTRUTURAÇÃO POR TIPO DE INVESTIMENTO;
- UTILIDADE PARA ORIENTAR MELHORIAS PRÁTICAS;
- FOCO EM RECOMENDAÇÕES ACIONÁVEIS.
CONTEXTO: dos clientes sobre diferentes tipos de investimentos (renda fixa, ações, fundos imobiliários, previdência privada e criptoativos).
DADOS DISPONÍVEIS: a base contém a data da resposta, a faixa etária do investidor, a faixa de renda do investidor, a faixa de valor patrimonial do investidor, o histórico de investimento do investidor nos últimos cinco anos, as opções de investimento, o histórico de cada investimento durante os últimos cinco anos.
CRITÉRIOS DE ANÁLISE: os clientes devem ser classificados por faixa etária, faixa de renda, faixa de valor patrimonial, histórico de investimento e preferência de investimento em uma escala que vai de zer até dez para cada opção de investimento.
CUIDADOS E RESTRIÇÕES:
- Use apenas os dados fornecidos;
- Não invente números;
- Não invente causas;
- Não invente conclusões;
- Não exponha dados pessoais;
- Não exponha informação sensível;
- Se houver informação insuficiente, indique a limitação;
- Use linguagem simples, direta e voltada para tomada de decisão.
```
